## 5. 功能与额度

### 5.1 已上线 / 已实现

| 模块 | 说明 |
| --- | --- |
| 登录 | `wx.login` → `/api/login`。可同时换旧号、新号 code |
| 生成 | `POST /api/tryon` 立即回 `taskId`，后台排队；「我的」看历史 |
| 衣柜 | 批量上传、异步抠图/分类、多选带到生成页 |
| 今日搭配 | 场合 + 天气（自动或手选）→ 从衣柜推荐 → 生成 |
| 收藏 / 历史 | 收藏套装、生成历史（含配件回填） |
| 积分 | 每日免费次数用完后扣积分；失败返还 |
| 兑换码 | 「我的」自助兑换；CLI / 管理接口生成 |
| 会员支付 | 月卡 ¥9.9 / 年卡 ¥99 / 永久 ¥128。旧号可买；新号等认证+关联 |
| 激励广告 | 代码有，广告位 ID 为空，后端开关默认关 |

### 5.2 默认额度（`.env` 可改）

| 权限 | 免费版 | 会员 |
| --- | ---: | ---: |
| 每日免费生图 | 3 | 10 |
| 衣柜 | 10 件 | 30 件 |
| 模特照 | 10 张 | 30 张 |
| 收藏套装 | 20 套 | 40 套 |
| 衣柜日上传 | 约 30 | 约 50 |

新用户赠送积分看 `FREE_SIGNUP_CREDITS`（生产常为 0）。每次生成默认扣 1 积分。

「每日」按 SQLite UTC 日期，约等于北京时间每天 08:00 重置。

## 7. 日常运营

用户在「我的」顶部看 **账号 #数字**，那就是 `userId`。充值前让用户再确认一次。

在服务器仓库根（或 `server/` 上一级）执行：

```bash
node server/scripts/credits.js balance 123
node server/scripts/credits.js grant 123 20 客服补偿
node server/scripts/credits.js gen-code 20 10
node server/scripts/credits.js list-codes
node server/scripts/credits.js membership 123 member 30
node server/scripts/credits.js membership 123 member
node server/scripts/credits.js membership 123 free
```

配置了 `ADMIN_TOKEN` 时，也可用请求头 `x-admin-token` 调：

- `POST /api/admin/credits/grant`
- `POST /api/admin/membership`
- `POST /api/admin/redeem-codes`

令牌不要放进 URL 或前端。

## 10. 实现注意

- **双号登录**：`server/wechat-login.js` 依次用 `WX_APPID`、`WX_APPID_2` 换 code。
- **双号支付**：下单用当前小程序 AppID 签 JSAPI；openid 必须属于同一个 AppID。新号未认证/未绑商户会失败。
- **生成队列**：提交即返回；积分先预扣，失败或重启中断会退回。
- **今日搭配**：新号去掉了 `getFuzzyLocation`，避免上传被拒；用手选天气。旧号若仍开通定位则走定位。
- **文案**：对外不要写具体模型名。结果页建议标「AI 生成」，过审更稳。

## 12. 故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 新号「微信登录失败」 | 只有旧号 `WX_SECRET`，或 Secret 错 | 确认 `WX_APPID_2`/`WX_SECRET_2`；错了去后台重置 |
| 新号「appid和openid不匹配」 | 支付仍用旧 AppID，或未按当前 AppID 下单 | 确认已部署按 AppID 下单的代码；体验版 ≥ 1.0.4 |
| 新号下单提示先认证 AppID | 新号未微信认证 | 先认证，再关联商户号 |
| 上传 `invalid ip` | 出口 IP 不在白名单 | 只在 `111.228.14.193` 传，白名单只留这个 IP |
| 请求合法域名失败 | 新号没加 `api.mingge.asia` | 开发设置里加上 request/uploadFile/downloadFile |
| 衣柜一直「处理中」 | 抠图/分类失败 | `pm2 logs ai-outfit`；查火山与 rembg |
| 今日搭配要定位 | 新号无定位权限 | 用手选天气；或去后台开通模糊位置 |
| 生成失败 / 超时 | 方舟配额或网络 | 看日志和火山账单 |
| 磁盘涨 | `data/uploads` | 备份后清过期图 |

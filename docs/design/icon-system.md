# 图标系统

项目使用 Tabler Icons 的 PNG 版本，图标位于：

- 小程序：`miniprogram/assets/icons/`
- 网页预览：`web-preview/assets/icons/`

许可证副本为各目录内的 `TABLER_LICENSE.txt`。

## 规则

- 常规图标使用深巧克力色，激活状态使用鼠尾草绿。
- 深色按钮或深色圆形状态标记内的图标转为白色，保证对比度。
- TabBar 使用 64×64 PNG，默认态和激活态分别提供独立资源。
- 分类、场合和天气图标按语义别名引用，例如 `category-top.png`、`occasion-commute.png`、`weather-rain.png`。
- 不新增 Emoji、Unicode 装饰符号、内联 SVG 或 CSS 绘制图标。

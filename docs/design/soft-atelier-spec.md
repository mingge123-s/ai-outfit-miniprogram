# 时衣集 · Soft Atelier 视觉规范

## 设计方向

方案 2「柔暖私人衣橱」把小程序定义为安静、亲近、有生活气息的私人衣橱。界面以真实衣物和穿搭结果为主角，装饰克制，避免工具感过强、过度圆润、发光渐变与表情符号。

唯一视觉基准为 `docs/design/soft-atelier-reference.png`，实现与后续迭代均以该图为准。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 页面燕麦底 | `#F7F1E8` |
| 卡片暖白 | `#FFFCF7` |
| 深巧克力正文 | `#3F322A` |
| 次级文字 | `#81746A` |
| 鼠尾草主色 | `#5F755F` |
| 鼠尾草浅底 | `#E8EEE5` |
| 低饱和杏色 | `#D89A6A` |
| 杏色浅底 | `#F4E6D8` |
| 描边 | `#DED4C7` |

主按钮使用纯鼠尾草绿，不使用渐变。危险或失败信息使用低饱和砖红，仅作为状态色。

## 字体与层级

- 品牌名、页面主标题、结果页标题：`Songti SC / STSong / Noto Serif SC`。
- 操作、正文、数字标签：系统无衬线中文字体栈。
- 宋体用于营造衣橱手帐感，不用于长段正文或小尺寸按钮。
- 标题强调由字号和留白完成，不依赖高饱和颜色。

## 形状与间距

- 页面左右留白：`28–32rpx`。
- 卡片圆角：`18–24rpx`。
- 主按钮圆角：`18–20rpx`，最低高度 `78–88rpx`。
- 卡片使用 `2rpx` 暖灰描边；阴影只用于层级悬浮，透明度保持克制。
- 分类筛选使用低矮胶囊；选中态为鼠尾草绿底和白字。

## 图片

- 首页：晨光、木质、亚麻、真实衣橱摄影。
- 衣物：统一燕麦米背景的单件产品照，主体完整，不出现文字、品牌、水印或人物。
- 空状态：保留真实静物感，不使用卡通人物或表情符号。
- 生成结果与收藏：结果图优先，操作按钮退后，不用装饰性大色块抢占画面。

## 页面结构

- 主导航保留：首页、衣柜、收藏、我的。
- 首页承担品牌与四个核心入口；今日搭配保留主导航；选衣、结果、Picker 使用专注任务的次级页结构。
- 所有页面应包含与数据状态匹配的加载、空、失败或处理中反馈。
- 所有可见功能图标统一使用 Tabler 线性图标 PNG，不使用 Emoji、文字符号或手绘 SVG。
